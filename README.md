## Funcionalidade do projeto  
O sistema tem como sua funcionalidade o monitoramento e a análise de dados de uma simulação de uma missão espacial experimental, onde após a recepção dos dados é realizado uma análise técnica sobre o status atual da nave, assim gerando feedbacks de acordo com os resultados.
